# PLP Python Week 8 Final Project: Multi-Tool Utility Package

## Overview
This repository contains a modular Python application that brings together core programming concepts—loops, functions, mutable data structures, conditionals, and user input validation—into a interactive command-line interface.

## Toolkit Contents
- `toolkit_plan.txt`: The initial planning blueprint outlining tool features, UI text, and program logic structures.
- `toolkit.py`: The main program containing:
  1. **Quick To-Do List**: Dynamic task manager using lists and loop controls.
  2. **Simple Calculator**: Handles mathematical operations and prevents division by zero using conditional validation.
  3. **Number Guessing Game**: A guess-tracking game utilizing pseudo-random numbers and controlled loops.

## How to Run
1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Execute the script using Python 3:
   ```bash
   python toolkit.py
